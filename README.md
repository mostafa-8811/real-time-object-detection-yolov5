# Real-Time Object Detection using YOLOv5 & OpenCV

A modular Python application for real-time object detection using pre-trained YOLOv5 models via PyTorch Hub and live camera streaming with OpenCV.

## Features
- **Real-Time Webcam Detection:** Runs live inference on video input with OpenCV rendering.
- **Static Image Inference:** Processes single image files for object detection.
- **Modular Pipeline:** Separated helper functions for model loading, image processing, and webcam streams.

## Tech Stack
- **Language:** Python 3.x
- **Frameworks & Libraries:** PyTorch, YOLOv5, OpenCV, NumPy
